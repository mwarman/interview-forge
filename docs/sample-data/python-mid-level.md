# Software Engineer, Python & TypeScript (Mid-Level)

## **Opportunity**

We are building a highly scalable, real-time data processing and analytics platform that empowers enterprise customers to make critical operational decisions. As we scale our infrastructure to support an expanding user base and increasing data throughput, we need an experienced engineer who can design and maintain robust, high-performance backends while seamlessly connecting them to rich, responsive user interfaces. This role matters because you will be directly responsible for the core services that process, store, and expose our mission-critical data.

This is a hands-on, full-stack engineering role requiring an absolute mastery of Python backend architectures and modern TypeScript frontends. You will spend roughly 70% of your time designing APIs, writing clean server-side logic, and orchestrating cloud-native infrastructure, and 30% crafting intuitive single-page applications. The ideal candidate is a seasoned technical professional who thrives in a collaborative environment, acts with a high degree of autonomy, and maintains a relentless focus on code quality, test coverage, and architectural reliability.

## **Requirements**

- 8+ years of professional software engineering experience designing, building, and maintaining production-grade backends using Python
- 5+ years of deep experience with modern Python web frameworks, specifically FastAPI, Flask, or Django
- 4+ years of professional experience building responsive single-page applications (SPAs) using TypeScript and React or Vue.js
- 3+ years of practical experience containerizing applications using Docker and orchestrating them via Kubernetes or AWS ECS
- 3+ years of experience developing and deploying serverless functions using AWS Lambda, Google Cloud Functions, or Azure Functions
- Extensive experience designing, implementing, and documenting secure RESTful APIs and GraphQL endpoints
- Strong proficiency with relational databases (PostgreSQL, MySQL) and NoSQL datastores (Redis, DynamoDB), including query optimization and schema design
- Solid understanding of CI/CD pipelines (GitHub Actions, GitLab CI, or Jenkins) and infrastructure-as-code tools like Terraform or AWS CloudFormation
- Demonstrated experience writing comprehensive unit, integration, and end-to-end tests across the entire software stack

## **Your Responsibilities**

- Design, build, and optimize high-throughput Python backend services and APIs with a focus on low latency, security, and scalability
- Develop and maintain serverless computational workflows and event-driven architectures to process asynchronous data streams
- Architect and implement clean, reusable component libraries and state-management systems within our TypeScript frontends
- Lead code reviews, champion engineering best practices, and contribute to the evolution of internal documentation and style guides
- Partner closely with product managers and UX designers to break down complex product requirements into technical specifications and milestones
- Diagnose and resolve performance bottlenecks, memory leaks, and production incidents across both frontend and backend layers
- Monitor application health and performance using tools such as Datadog, New Relic, or AWS CloudWatch

## **You'll Love**

- Designing systems from first principles and owning their technical evolution from local development to cloud deployment
- Working with a modern, highly optimized tech stack devoid of legacy technical debt or rigid corporate red tape
- Collaborating with a deeply technical team that values architectural integrity, programmatic automation, and continuous learning
- Having a direct, measurable impact on product feature velocity and system performance every single week

## **How You Work**

- You are highly collaborative but technically opinionated—you actively participate in architectural debates and defend your logic with empirical evidence
- You operate with minimal structural overhead; you naturally self-organize, prioritize effectively, and maintain a high velocity of delivery
- You value radical candor, absolute clarity, and directness in both written and verbal technical communication
- You approach complex debugging and system failures with curiosity, patience, and a methodical, root-cause-oriented mindset

## **What Success Looks Like**

- Within the first 90 days, you have containerized and migrated two legacy background services to a serverless architecture, improving resource efficiency by 20%
- The new TypeScript application features you deliver consistently achieve over 85% test coverage and meet precise Core Web Vitals targets
- API response times for core data endpoints are optimized and maintained below a strict 150ms threshold under peak loads
- The engineering team successfully adopts your structural patterns for Python service boilerplate, drastically reducing the onboarding time for subsequent microservices
